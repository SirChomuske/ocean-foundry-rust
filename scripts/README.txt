Ocean Foundry
=============

Extract this folder anywhere and run OceanFoundry.exe. Nothing needs to be
installed.

Your settings are kept in the "OceanFoundry-data" folder that appears beside
the program. If that location cannot be written to, they go to
%LOCALAPPDATA%\OceanFoundry instead. Delete the folder to start afresh.

If the program ever closes unexpectedly, the details are in crash.log inside
that settings folder.

OceanFoundry-cli.exe is a command-line helper for diagnostics, for example:
    OceanFoundry-cli.exe devices     lists graphics cards and their check results
    OceanFoundry-cli.exe bench       measures calculation speed
Run it with no arguments to see everything it can do.

The "samples" folder holds example files for Minecraft Java 26.1.2:
    build-files        a small test build in every format, to try pasting
    ocean-test-runs    oceans from the first working version of the generator,
                       each with pictures and Litematica, WorldEdit and Axiom
                       files; its README.txt describes them

The appearance (Auto, Light or Dark) and the language are chosen at the
top right of the window.

Ocean Foundry 海洋铸造厂
======================

将此文件夹解压到任意位置，运行 OceanFoundry.exe 即可，无需安装任何东西。

设置保存在程序旁边的 "OceanFoundry-data" 文件夹中；如果该位置无法写入，
则保存到 %LOCALAPPDATA%\OceanFoundry。删除该文件夹即可恢复初始状态。

如果程序意外关闭，详细信息记录在设置文件夹内的 crash.log 中。

"samples" 文件夹包含适用于 Minecraft Java 26.1.2 的示例文件：
    build-files        各种格式的小型测试建筑，可用于试着粘贴
    ocean-test-runs    由生成器的第一个可用版本制作的海洋，每个都附有图片
                       以及 Litematica、WorldEdit 和 Axiom 文件

外观（自动、浅色或深色）和语言可在窗口右上角选择。
